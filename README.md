# Alpha-Factor-Discovery-and-Backtesting-Framework
• Developed a quantitative research pipeline in Python using Pandas, Scikit-Learn, and Yahoo Finance data across 10 NSE stocks.

• Engineered technical alpha factors including momentum, volatility, RSI, moving-average spreads, and volume-based indicators for return
prediction.

• Trained and evaluated Linear Regression and Random Forest models using out-of-sample testing to forecast future stock returns.

• Built stock-ranking portfolios and conducted historical backtesting with benchmark comparison to assess strategy performance and factor
effectiveness
